# Parkinson Detect

Небольшая нейронная сеть по классификации данных. На основании входных данных ввиде результатов анализов определяет наличие заболевания Паркинсона.

### Что используется

* pandas - для работы с датасетом
* sklearn - для обработки данных
* xgboost - для классификации входных данных

Для выполнения кода необходимо скопировать репозиторий и развернуть его в среде выполнения, например VSCode, GoogleColab и пр.
